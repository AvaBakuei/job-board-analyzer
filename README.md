# Job Board Analyzer

A simple Python project for fetching and analyzing job listings from the Arbeitnow API.

## Features

- Fetch job listings
- Display job information
- Filter jobs by city
- Analyze job skills

## Run

```bash
python main.py
```

## API

[Arbeitnow Job Board API](https://www.arbeitnow.com/api/job-board-api)
